# Storefront outcomes

- [x] **Assignment content and product catalog:** Import and present the product data and content from the attached E-Commerce assignment. Use the supplied brand and story, Nasarpor Kashi Heritage / Hala Kashi Heritage, artisans in Nasarpur, Sindh, authentic handmade Kashi pottery, the B2C + D2C model, and portfolio categories (decorative vases, wall plates, tiles, serving bowls, and custom nameplates). The assignment gives no per-SKU inventory or price list; identify storefront prices as illustrative and avoid presenting invented SKU details as facts from the assignment. The storefront uses the cover name consistently, records the name variation, includes source-assignment photos, and labels demo prices and sample availability.
- [x] **Responsive home page:** Provide a responsive storefront home page with featured products, promotional content, and clear shopping navigation; reflect the assignment's blue-and-white Kashi craft, artisan process, fair-trade purpose, customization, gift packages, and Pakistan-first market.
- [x] **Catalog discovery:** Provide category browsing, search, sorting, and filtering across the assignment's product categories.
- [x] **Product pages:** Provide product detail pages with imagery, pricing, descriptions, availability, variants where provided, and add-to-cart controls; support customization where described (names, logos, messages, special patterns), and do not invent assignment-provided variants.
- [x] **Persistent cart and order summary:** Provide a persistent shopping cart with quantity editing, item removal, subtotal, and order summary. The cart is stored in browser local storage and has empty/loading/error recovery states.
- [ ] **Checkout:** Provide a customer-facing checkout flow connected to the store's commerce backend. The approved blueprint has no selected Shopify backend or payment credentials; keep any unconnected/demo checkout clearly identified and do not claim that an order or payment was submitted to a live provider. The checkout form and confirmation-preview screen exist, but live commerce/order/payment integration remains open.
- [x] **Essential pages and navigation:** Include About, Contact, shipping information, returns, privacy, and terms. Preserve assignment policies: quality inspection before dispatch; verified breakage claims submitted with photo/unboxing video within 24 hours qualify for replacement/refund; three-day return/exchange only for damaged, incorrect, or materially different products; customer information only for order processing, delivery, support, and lawful communication; artisan-made Kashi authenticity and natural variations; fair, timely artisan payment. The assignment does not provide verified business support contact information; the Contact page makes that missing launch detail explicit.
- [x] **Accessible responsive states:** Deliver a responsive, accessible interface with loading, empty, error, and out-of-stock states. The tile unavailable state is explicitly illustrative, not live stock.
- [x] **Next.js and hosting readiness:** Implement in Next.js, organized for a GitHub repository and deployment on a compatible hosting service. The project uses Next.js static export and includes a GitHub Pages Actions workflow with an automatically configured repository base path.
